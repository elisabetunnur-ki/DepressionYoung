Physiological Systems

Node size reflects the number of individuals with the condition among those with depression, and node color indicates physiological system. Node sizes are scaled within each analysis and should not be compared across analyses. Edge thickness reflects adjusted comorbidity association strength. Exact adjusted odds ratios are shown in tooltips; the edge-filter scale is capped at 10.

The sibling-based PheWAS is a within-family comparison. Its comorbidity networks are reconstructed among depression-diagnosed individuals eligible for the sibling analysis and should not be interpreted as within-family edge estimates.
